Simulateur Git

Les trois zones de Git

1 Répertoire de travail

Vos fichiers, tels qu'ils sont sur le disque.

git add ↓

2 Staging area (index)

Ce qui partira dans le prochain commit.

git commit ↓

3 Dépôt local (.git)

L'historique enregistré : commits et branches.

Aide

Principe

Tapez de vraies commandes dans le terminal (en bas). Le graphe (en haut) se redessine après chaque commande : chaque cercle est un commit, chaque ligne horizontale une branche, avec sa propre couleur. Une phrase en italique explique ce qui vient de se passer.

Commandes de fichiers

  • touch notes.txt crée un fichier vide
  • echo "Bonjour" > notes.txt remplace le contenu du fichier
  • echo "Suite" >> notes.txt ajoute une ligne à la fin
  • cat notes.txt, ls, rm notes.txt, clear

Commandes Git disponibles

  • git init, git status, git add <fichier> ou git add .
  • git commit -m "message", git commit -am "message"
  • git log (--oneline, --graph, --all), git diff (--staged)
  • git branch, git branch nom, git branch -d nom
  • git checkout nom, git checkout -b nom, git switch nom, git switch -c nom
  • git merge nom (avance rapide, commit de fusion, conflits, --abort)
  • git help et git help <commande> ; help pour l'aide en français

reset, revert, cherry-pick, stash, tag, rebase et remote sont prévus dans une prochaine version.

Lire le graphe

  • Le temps va de gauche à droite ; un commit de fusion a un point central et deux traits entrants.
  • Les étiquettes colorées sont les branches ; l'étiquette blanche HEAD indique où vous êtes.
  • Survolez un commit pour voir son hash, son message et son auteur ; cliquez dessus pour insérer son hash dans le terminal.
  • Le bouton « Zones Git » ouvre le panneau des trois zones : répertoire de travail, staging area et dépôt local.

Raccourcis

  • ↑ ↓ historique des commandes · Tab autocomplétion (commandes, branches, fichiers)
  • Ctrl+L efface l'écran · cmd1 && cmd2 enchaîne deux commandes
  • Tout est sauvegardé automatiquement dans ce navigateur. « Annuler » revient à l'état d'avant la dernière commande.

Pour démarrer

git init
echo "Mon projet" > README.md
git add README.md
git commit -m "Premier commit"
git switch -c feature

Le simulateur n'a pas pu démarrer

Si vous avez ouvert index.html directement depuis le disque (adresse en file://), votre navigateur bloque sans doute les modules JavaScript (c'est le cas de Chrome et Edge).

Solution : dans le dossier du projet, lancez python3 -m http.server 8000 puis ouvrez http://localhost:8000 (ou utilisez l'extension « Live Server » de VS Code).
